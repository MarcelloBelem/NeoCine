# 🎬 NeoCine

## 🍿 Sobre o Projeto

O NeoCine é um aplicativo web em desenvolvimento para amantes de cinema! A ideia é criar uma plataforma intuitiva onde você pode:

- 🔍 Explorar uma vasta coleção de filmes
- 📋 Gerenciar listas pessoais de filmes assistidos
- ❤️ Criar e organizar listas de favoritos
- 📱 Experiência responsiva para mobile e desktop

Este é um projeto pessoal para apresentar conceitos de desenvolvimento web e organização de conteúdo cinematográfico.
